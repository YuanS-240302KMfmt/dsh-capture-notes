# dsh-capture-notes 需求文档（v0.7.0）

> 文档状态：**需求冻结 v0.7.0**（2026-11-10）
> 基线：v1.2 需求 + 0.6.0 实现
> 本轮范围：只明确需求与验收，不动代码。
> 决策：长时录屏验收推迟到 0.8.0；其余候选全部纳入 0.7.0；无多显示器环境。

## 1. 版本目标

0.7.0 是 0.6.0 之后的**稳定性与日常可用性版本**：

- 文件模式能处理真实长媒体和更多格式；
- 录制中断后能可靠恢复，退出后无残留进程；
- 文件任务可取消，失败信息可操作；
- 窗口有托盘与最近会话，文件译文状态可见；
- 不引入新的 AI 能力，不改变实时链路指标。

## 2. 范围决策

| 项 | 0.7.0 | 说明 |
|---|---|---|
| 60 分钟长时录屏验收 | **不做**，推迟 0.8.0 | 本轮没有测试时间；录制实现保持现状 |
| 60 分钟长时文件 | **做** | 用 1080p、60 分钟素材验收 |
| 崩溃恢复 | **做** | 强杀 DSH/窗口后恢复 |
| 文件格式边界 | **做** | MKV、纯音频、无音轨、内嵌字幕 |
| 托盘与退出 | **做** | 关闭到托盘、退出收尾 |
| 取消封装/烧录 | **做** | 任务可取消并清理 |
| 错误可操作化 | **做** | 麦克风、磁盘、无音轨 |
| 最近会话 | **做** | 最近 10 个，打开目录/重跑后处理 |
| 文件译文状态 | **做** | 只展示状态，不内置 MT |
| 多显示器 | **不做** | 当前只有单屏；保留现有选择逻辑 |
| 说话人聚类/重叠 | **不做** | 0.8.0 或 1.0 单独立项 |
| 云端 ASR / URL / 暂停 / 区域录制 / 实时字幕叠加 | **不做** | 维持 v1 边界 |

## 3. 非目标

- 不改变实时/录屏的 p95 ≤ 2.5 s 指标，不引入 GPU。
- 不做声纹注册、说话人真实身份识别、TTS。
- 不把文件译文改成模块内置 MT；译文仍由 agent 写 `translation.<target>.json`。
- 不做自动纪要；纪要仍由 `capture-notes` 技能完成。
- 不改 `segments.json` 的既有字段语义；`speaker` / `speakers` / `overlap` 继续保留为空/false。
- 不承诺 Windows 之外的平台。

## 4. 功能需求

### 4.1 长时文件（FR-FL）

| ID | 需求 | 验收 |
|---|---|---|
| FR-FL1 | 60 分钟、1080p、H.264/AAC 文件可完整跑完文件流水线 | 生成 transcript、segments、subtitles、session、成片；进程不崩 |
| FR-FL2 | 进度持续更新，不出现长时间无进展 | 连续 5 分钟无进度视为失败；取消按钮可用 |
| FR-FL3 | 成片时长与源文件误差 ≤ 1 s，字幕时间轴误差 ≤ 300 ms | 抽 3 个时间点核对 |
| FR-FL4 | 记录耗时、峰值内存/CPU、输出大小到 `session.json` 或 `work` 日志 | 跑完可在清单里读到 |
| FR-FL5 | 磁盘不足时在开始前失败并提示所需空间 | 不产生半成品 mp4 |

### 4.2 崩溃恢复（FR-CR）

| ID | 需求 | 验收 |
|---|---|---|
| FR-CR1 | 录制中强杀 DSH/窗口，重启后自动恢复未完成录制 | 出现 `sessions/recovered-*`，`screen.mp4` 可播放，`crashRecovered=true` |
| FR-CR2 | 恢复只使用完整/可解码的 TS 分片，损坏尾片丢弃 | 恢复成片解码 0 error |
| FR-CR3 | 退出/崩溃后不残留本模块的 `ffmpeg.exe`、`pwsh.exe` | 任务管理器无相关进程 |
| FR-CR4 | 恢复失败时给出原因和分片路径，不删除原始分片 | 用户可手工取走 `native/video` |
| FR-CR5 | 正常停止与崩溃恢复不会重复生成同一会话 | 会话 id 唯一，清单不重复 |

### 4.3 文件格式边界（FR-FF）

| ID | 需求 | 验收 |
|---|---|---|
| FR-FF1 | 支持 MKV（H.264/AAC）软/硬字幕 | 产物与 MP4 一致，软字幕轨可开关 |
| FR-FF2 | 支持纯音频 MP3/M4A/WAV | 出 transcript/subtitles，不生成 mp4，UI 说明“无视频” |
| FR-FF3 | 无音轨视频在抽音阶段失败 | 不创建空会话；错误说明“文件没有音频” |
| FR-FF4 | 内嵌字幕可抽取为 SRT | CLI `--subs-only`（或窗口新增独立入口）产出可用 SRT；无字幕时明确报错；不与窗口「仅字幕」混淆 |
| FR-FF5 | 支持长文件名、空格、中文、特殊字符 | `out/<slug>` 合法，不覆盖其他任务 |
| FR-FF6 | 不支持的编码/容器给出可操作错误 | 提示下一步（转码/换文件），不抛裸异常 |

### 4.4 托盘与退出（FR-TR）

| ID | 需求 | 验收 |
|---|---|---|
| FR-TR1 | 窗口关闭时隐藏到托盘，不直接退出 | 托盘图标存在，录制继续 |
| FR-TR2 | 托盘菜单：显示窗口 / 退出 | 显示可恢复窗口；退出会先收尾 |
| FR-TR3 | 托盘显示空闲/录制中状态与计时 | 与窗口状态一致 |
| FR-TR4 | 退出时停止录制、封装、清理临时文件 | 无残留进程/半成品；再次启动正常 |
| FR-TR5 | 只允许一个托盘图标 | 重复显示不产生多个图标 |

### 4.5 取消任务（FR-CA）

| ID | 需求 | 验收 |
|---|---|---|
| FR-CA1 | 文件任务在抽音/识别/封装/烧录阶段均可取消 | 状态变为 `cancelled`，UI 可继续新任务 |
| FR-CA2 | 取消时终止识别 worker 与 ffmpeg | 无孤儿进程 |
| FR-CA3 | 取消清理临时文件，不留下最终半成品 | `out/<slug>` 无残缺 mp4；`work` 可清理 |
| FR-CA4 | 取消后再次处理同一文件可正常完成 | 不被上次锁/临时文件阻塞 |

### 4.6 错误可操作化（FR-ER）

| ID | 需求 | 验收 |
|---|---|---|
| FR-ER1 | 麦克风被拒时显示原因与「打开麦克风设置」按钮 | 点击打开 `ms-settings:privacy-microphone`；保留勾选/明确说明回退 |
| FR-ER2 | 磁盘不足、无音轨、格式不支持给出下一步 | 文案可执行，不是裸异常 |
| FR-ER3 | 麦克风失败不再被 listening 快照清掉提示 | 错误条持续到用户处理或重新开始 |
| FR-ER4 | 错误日志写窗口/会话目录，便于反馈 | 可从 UI 或路径找到 |

### 4.7 最近会话（FR-HS）

| ID | 需求 | 验收 |
|---|---|---|
| FR-HS1 | 文件 tab 显示最近 10 个会话 | 按时间倒序；含类型/时间/状态 |
| FR-HS2 | 可打开会话目录 | 资源管理器定位正确 |
| FR-HS3 | 录屏会话可重跑后处理（软/硬/仅字幕），不重新识别 | 复用 `segments.json`，生成新成片 |
| FR-HS4 | 不提供删除功能 | 避免误删；清理仍由用户手工完成 |

### 4.8 文件译文状态（FR-TS）

| ID | 需求 | 验收 |
|---|---|---|
| FR-TS1 | 文件 tab 显示译文状态：未生成 / 已生成 / 已应用 | 读取 `translation.<target>.json` 与 `session.json` |
| FR-TS2 | 只展示状态与路径，不内置翻译 | 不调用 MT API；不改变 Q1 决议 |
| FR-TS3 | 可复制/查看 agent 提示 | 给出“让 agent 生成译文”的入口说明 |

## 5. 验收指标

- 长文件：60 分钟跑完，进程不崩，输出可播放；字幕误差 ≤ 300 ms；峰值内存 ≤ 2.5 GB（超出需记录并评估）。
- 恢复：强杀后恢复成功；恢复成片解码 0 error；无孤儿进程。
- 格式：FR-FF1–FF6 全部通过；失败场景不产生空会话/半成品。
- 托盘：关闭/显示/退出/单实例全部通过；退出无残留。
- 取消：4 个阶段各取消一次；无最终半成品；可立即重跑。
- 错误：麦克风、磁盘、无音轨三类错误均可操作。
- 回归：v1 的实时、短录屏、文件软/硬/仅字幕、译文应用、技能纪要全部保持通过。

## 8. 风险与待确认

| 风险 | 处理 |
|---|---|
| 60 min 长文件测试耗时/素材 | 用户提供真实 1080p 长视频；先跑 10 min 预热，再跑 60 min |
| 托盘 WPF NotifyIcon 生命周期 | 单实例锁；退出路径统一走收尾函数 |
| 烧录取消的 ffmpeg 清理 | 先 kill 进程组，再删临时文件；失败只告警不阻塞退出 |
| 崩溃恢复依赖 DSH 重启 | 用强杀 + 重启验证，不用“正常关闭”代替 |
| 长时录屏未验证 | 明确写入 0.7.0 已知限制，0.8.0 专项 |

**已确认（2026-11-10）**：60 分钟素材由用户提供；最近会话、托盘状态计时、文件译文状态均纳入 0.7.0。
