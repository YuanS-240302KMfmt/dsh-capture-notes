# dsh-capture-notes 0.7.2

> 日期：2026-11-11 · 版本：`0.7.2`

## 改动

### 文件 tab 视频封面

- 文件选中/拖入后，在字幕区显示视频第 1 秒的封面；
- 封面用模块自带 ffmpeg 抽取到 `runtime-data\file-thumb.jpg`，WPF `BitmapImage` 加载；
- 音频文件显示“音频文件（无视频封面）”，抽取失败显示“无法生成视频封面”；
- 封面显示文件名，保留拖入/选择的提示；
- 修复含空格/长文件名：`Start-Process -ArgumentList` 会把路径拆开，改用 `ProcessStartInfo.ArgumentList`；已用 `... 和另外 11 个页面 ...mp4` 实测出封面。

### 打开输出目录

- 底部状态栏新增「打开输出」按钮（实时 tab 隐藏，录屏/文件 tab 显示）；
- 文件模式：优先打开当前 `out\<slug>`，没有结果时打开 `out\`；
- 录屏模式：优先打开 `sessions\<lastSessionId>`，没有会话时打开 `sessions\`；
- 路径不存在时显示错误条，不静默失败。

## 验证

- 文件 tab 预览图：封面、文件名、打开输出按钮均显示；
- 深色 ComboBox 与 0.7.1 拖拽功能保持正常；
- 用户手动确认：长文件名视频封面正常，不再显示「无法生成视频封面」。

待补：音频文件无封面提示的人工确认；「打开输出」点击后的目录跳转人工确认。
